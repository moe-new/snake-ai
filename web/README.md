# 实验台（网页版）

六条蛇用视频里同一套算法自己跑，你来看、拖、单步，不用自己操作。整个页面是一个离线 HTML 文件，零外部请求。

```sh
open web/dist/tuilu-lab.html   # 直接打开构建好的页面
node web/build.js              # 改了代码后重新打包 → web/dist/tuilu-lab.html（约 185 KB）
node web/check.js              # 用同一套引擎重下片中的对局，和视频里的数字逐项比对
```

只需要 Node（构建和核对都不装依赖）。页面支持 iOS 15.4、Chrome 92 以上的浏览器。

## 两个视图

**单局**（默认）：选一条蛇、棋盘（6–16，奇数也行）、穿边、种子。

- 打开"自定义大小"会多出宽、高两个输入框，每边 3–20 格，长方形也行。点任一预设就回到正方形。
- 穿边时，蛇身和所有画线都是连续的一条：到边缘截平，从对边接着出来。
- 播放/暂停（点棋盘也行）、单步、拖进度条、变速（慢 · 1× · 4× · 16× · 64×）。进度条上的金色刻度是每一口。
- 每一步下面一句话说明它为什么这么走，棋盘上画出对应的线：蓝色是去吃的路，金色是退路或环线，箭头是单行道，红色是回不去或撞上的地方。暂停或"慢"速时，还画出"试吃"的那条虚影。
- 结束时（吃满 / 撞死 / 原地绕圈）有横幅说明怎么结束的。

**赛跑**：六条蛇同一个种子、同一个棋盘一起跑，跑完列成绩。默认种子 395，就是视频终章那一局。

键盘：空格暂停 · ← → 单步（Shift 十步）· 1–6 换蛇 · R 换种子。选择会存在 localStorage，存不了就用默认值。

## 和视频一致

页面里的引擎就是视频用的那一份（`engine/`），每一步的说明也来自引擎当时的判断（`lab/play.js` 的 `probe()`），不是事后猜的。`node web/check.js` 会重下这些对局（8×8、不穿边）：

| 蛇 | 种子 409 | 种子 395（比赛） | 种子 1–100 |
| --- | --- | --- | --- |
| 莽夫 | 第 155 步撞死 | 第 104 步撞死 | 0 局吃满，平均占满 42% |
| 谨慎 | 原地绕圈 | 第 119 步起绕圈 | 2 局吃满 |
| 循规蹈矩 | 1107 步吃满 | 1079 步 | 局局吃满，平均 1010 步 |
| 抄近路 | 591 步 | 643 步 | 局局吃满，平均 674 步 |
| 单行道 | 485 步 | 526 步 | 局局吃满，平均 558 步 |
| 步步为营 | 523 步 | 445 步 | 局局吃满，平均 536 步 |

种子决定食物出现在哪：同一个种子，开局一模一样。

## 文件

| 文件 | 内容 |
| --- | --- |
| `engine/snake.js` | 棋盘、种子、食物、BFS 等公共部分（`TailSnake`） |
| `engine/four-way.js` | 谨慎：四向 BFS，吃之前先试吃，回得到尾巴才吃 |
| `engine/hybrid.js` | 循规蹈矩和抄近路：沿一条哈密顿环线走，抄近路时不越过尾巴；`createGame()` 按名字建出每一种蛇 |
| `engine/tiled-directed.js` | 步步为营：2×2 小圈拼成的单行道路网上，吃之前先确认吃完整条蛇躺在一条环线上 |
| `engine/c-directed.js` | 单行道：2024 年那份 C 代码的规则（`../c/c-original.c`），逐行搬成 JavaScript |
| `engine/bfs-handoff.js`、`adaptive.js`、`simple-directed-graph.js`、`tiled-simple.js` | 研究过程中的其他变体，`createGame()` 会用到，实验台不直接展示 |
| `lab/index.html` | 页面骨架；`build.js` 往里填样式、标题图、引擎和代码 |
| `lab/style.css` | 夜间配色，手机优先，≥960px 两栏 |
| `lab/draw.js` | 棋盘、蛇、苹果、发光线，照视频的画法移植；穿边时把线展开成一条，再按经过的每份棋盘切开画 |
| `lab/play.js` | 六条蛇；`Recording` 分片记录一局（不卡页面），每步之前用 `probe()` 记下原因 |
| `lab/app.js` | 界面：单局、进度条、赛跑、说明文字、WebAudio 小音效（默认关） |
| `lab/title.png` | 标题"退路"，思源宋体 Black 渲成的小图 |
| `build.js` | 打包成 `dist/tuilu-lab.html` |
| `check.js` | 重下片中的对局并核对数字 |

引擎文件之间靠全局变量互相引用，要按 `build.js` 里的顺序加载；在 Node 里也可以直接 `require`。改了引擎的规则，要同步改 `lab/app.js` 里解释每一步的 `whyText()`。

调试：`window.__lab.step(t)` 手动推一帧（无头截图时没有动画帧），`window.__lab.S` 是当前状态。
